# Graphic Design

Optional local media for **Graphic Design** projects.

- One folder per project: `projects/graphic-design/<project-id>/`
- Keep files small (export web-sized `.webp` or `.jpg`, ideally under 400 KB each).
- Large source files (PSD, high-res exports) should NOT go here. Host them externally if needed and paste the link into `data/projects.json`.
- Only upload approved, privacy-safe versions of anything.

See the main `README.md` for the full guide.
