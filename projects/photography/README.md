# Photography

Optional local media for **Photography** projects.

- One folder per project: `projects/photography/<project-id>/`
- Keep files small (export web-sized `.webp` or `.jpg`, around 1600 px on the long edge, ideally under 400 KB each).
- Full-resolution originals should NOT go here. Host them externally and paste the link into `data/projects.json`.
- Only upload approved, privacy-safe versions of anything.

See the main `README.md` for the full guide.
