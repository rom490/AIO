# AI Experiments

Optional local media for **AI Experiments** projects.

- One folder per project: `projects/ai-experiments/<project-id>/`
- Keep files small (stills as `.webp` or `.jpg`, ideally under 300 KB).
- Large videos and originals should NOT go here. Host them externally and paste the link into `data/projects.json`.
- Only upload approved, privacy-safe versions of anything.

See the main `README.md` for the full guide.
