# Video Editing

Optional local media for **Video Editing** projects.

- One folder per project: `projects/video-editing/<project-id>/`
- Keep files small (thumbnails and stills as `.webp` or `.jpg`, ideally under 300 KB).
- Large videos and originals should NOT go here. Host them externally (YouTube unlisted, Vimeo, Google Drive) and paste the link into `data/projects.json`.
- Only upload approved, privacy-safe versions of anything.

See the main `README.md` for the full guide.
