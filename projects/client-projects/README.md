# Client Projects

Optional local media for **Client Projects**.

**Privacy first:** never commit original client files. Only upload versions the client has approved for public display (blurred, redacted or otherwise privacy-safe). Everything in this repository is public.

- One folder per project: `projects/client-projects/<project-id>/`
- Keep files small (thumbnails and stills as `.webp` or `.jpg`, ideally under 300 KB).
- Large videos should NOT go here. Host the approved version externally and paste the link into `data/projects.json`.
- Set `"clientProject": true` on the project in `data/projects.json`.

See the main `README.md` for the full guide.
